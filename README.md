# Tonans

Tonans is Flintglade's local-first microgrid scenario workbench. It compares transparent battery, tariff, renewable-generation, and outage-planning scenarios without controlling equipment or pretending to be a safety-certified design authority.

This repository is under active release-candidate development and must not be published in the current task. The authoritative requirements and verification gates are in [PRODUCT-SPEC.md](PRODUCT-SPEC.md).
