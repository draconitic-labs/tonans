# Contributing to Tonans

The Tonans source is available for inspection and evaluation under [LICENSE.md](LICENSE.md). It is not open-source software, and outside code contributions are not being accepted at this time.

Bug reports, model questions and documentation corrections are welcome as issues. Include the Tonans version, your operating system and a synthetic example; do not attach real site data.

Report security problems privately as described in [docs/SECURITY.md](docs/SECURITY.md).
